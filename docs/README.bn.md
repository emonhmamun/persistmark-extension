# 🖍️ PersistMark — পার্মানেন্ট টেক্সট হাইলাইটার

**যেকোনো ওয়েবসাইটের যেকোনো লেখা হাইলাইট করুন — আর সেটা চিরকালের জন্য সেভ থাকবে।**
রিফ্রেশ করুন, ব্রাউজার বন্ধ করুন, কম্পিউটার রিস্টার্ট করুন — পরে ফিরে এসে দেখবেন আপনার হাইলাইটগুলো ঠিক জায়গায় দাঁড়িয়ে আছে। 💜

## ✨ ফিচারসমূহ

| ফিচার | বর্ণনা |
|---|---|
| 🎨 **৮টি রঙ + কাস্টম কালার** | ৮টি প্রিসেট রঙ + 🎚️ প্যানেল থেকে **যেকোনো রঙ** বাছাই করা যায় |
| 💧 **Intensity কন্ট্রোল** | প্রতিটি হাইলাইট কতটা গাঢ়/হালকা হবে — স্লাইডার দিয়ে নিজের মতো সেট করুন |
| 🪄 **সিলেকশন টুলবার** | লেখা সিলেক্ট করামাত্রই উপরে ছোট টুলবার — এক পাশে ৮টি রঙ + 🎚️ কাস্টম প্যানেল, আরেক পাশে **Highlight বাটন** (বাটনের রঙই = লাস্ট-ইউজড রঙ)। **বাটনে ক্লিক না করা পর্যন্ত হাইলাইট হয় না** |
| 🧠 **লাস্ট-কালার মেমোরি** | কোনো রঙ দিয়ে হাইলাইট করলে সেটাই ডিফল্ট হয়ে যায় — পরের বার শুধু বাটনে ক্লিক করলেই সেই রঙে হাইলাইট |
| 🗑️ **সহজ ডিলিট (৪ উপায়)** | হাইলাইটে ক্লিক → Delete · সিলেক্ট → 🗑️ · রাইট-ক্লিক → Remove · `Alt+Shift+D` |
| ↩️ **Undo টোস্ট** | ডিলিট করলে নিচে "Undo" বাটন আসে — ৬ সেকেন্ডের মধ্যে এক ক্লিকে ফিরে আসে! |
| ⚡ **হাইলাইটার মোড** (ঐচ্ছিক) | চালু করলে সিলেক্ট করামাত্রই অটো হাইলাইট (`Alt+Shift+H`) — ডিফল্টে **বন্ধ**, পপআপ/অপশন থেকে নিয়ন্ত্রণ |
| 🌙 **ডার্ক/লাইট মোড সাপোর্ট** | পেজের ব্যাকগ্রাউন্ড বুঝে নিয়ে রঙ নিজে থেকেই অ্যাডজাস্ট হয় |
| 🔒 **পার্মানেন্ট সেভ** | রিফ্রেশ / রিস্টার্ট / পুনরায় ভিজিটেও হাইলাইট ফিরে আসে |
| 🧠 **স্মার্ট টেক্সট অ্যাংকরিং** | লেখার আগে-পরের কনটেক্সট মনে রাখে, তাই লেআউট বদলালেও খুঁজে পায় |
| 📋 **হাইলাইট তালিকা** | আইকনে ক্লিক করলে পেজের সব হাইলাইটের তালিকা — সার্চ + ক্লিক করলেই সেখানে যাওয়া |
| 📝 **নোট** | প্রতিটি হাইলাইটে নোট যোগ করা যায় (হাইলাইটে ক্লিক করুন) |
| 🖱️ **রাইট-ক্লিক মেনু** | সিলেক্ট করা লেখায় রাইট-ক্লিক → রঙ বেছে হাইলাইট |
| ⌨️ **কীবোর্ড শর্টকাট** | `Alt+Shift+H` (মোড টগল) · `Alt+Shift+L` (সিলেকশন হাইলাইট) · `Alt+Shift+D` (সিলেকশনের হাইলাইট মুছুন) |
| 🔢 **ব্যাজ কাউন্ট** | টুলবার আইকনে দেখায় বর্তমান পেজে কতটি হাইলাইট আছে |
| 💾 **ব্যাকআপ** | সব হাইলাইট JSON ফাইলে Export / Import (Merge বা Replace) |
| 🔄 **ডিভাইস সিঙ্ক** (ঐচ্ছিক) | Chrome Sync-এ সেভ করলে অন্য কম্পিউটারেও হাইলাইট পাবেন |
| 🚫 **সাইট ব্লকলিস্ট** | নির্দিষ্ট সাইটে এক্সটেনশন বন্ধ রাখার অপশন |
| 🖼️ **iframe সাপোর্ট** | এমবেড করা ফ্রেম/ডকুমেন্টেও কাজ করে |
| 🕸️ **SPA ও ডাইনামিক পেজ** | Facebook/YouTube-এর মতো পেজ ও lazy-load কনটেন্টেও কাজ করে |
| 🔐 **১০০% প্রাইভেট** | কোনো অ্যাকাউন্ট নেই, ট্র্যাকিং নেই, নেটওয়ার্ক রিকোয়েস্ট নেই — সব ডেটা ব্রাউজারেই |

## 📥 ইনস্টল করার নিয়ম (Chrome / Edge / Brave)

1. `text-highlighter-extension` ফোল্ডারটি (অথবা `persistmark-extension.zip` থেকে আনজিপ করা ফোল্ডার) আপনার কম্পিউটারে রাখুন।
2. ব্রাউজারে যান: **`chrome://extensions`** (Edge-এ `edge://extensions`, Brave-এ `brave://extensions`)
3. ডান দিকে উপরে **Developer mode** চালু করুন।
4. **Load unpacked** বাটনে ক্লিক করে `text-highlighter-extension` ফোল্ডারটি সিলেক্ট করুন।
5. ব্যাস! টুলবারে 🖍️ আইকনটি চলে আসবে। পিন করে রাখুন।

> 💡 **লোকাল HTML ফাইল টেস্ট করতে চাইলে:** `chrome://extensions` → PersistMark → Details → **"Allow access to file URLs"** চালু করুন।

## 🚀 ব্যবহার শুরু করুন (৩ ধাপ)

1. **সিলেক্ট করুন** — যেকোনো ওয়েবসাইটে লেখা সিলেক্ট করুন (মাউস ড্র্যাগ, ডাবল-ক্লিক, ট্রিপল-ক্লিক বা কীবোর্ড — যেভাবেই হোক)। সাথে সাথেই লেখার উপরে ছোট্ট টুলবার ভেসে উঠবে এবং **সিলেকশন থাকা পর্যন্ত থাকবে**।
2. **হাইলাইট করুন** — বাটনে ক্লিক না করা পর্যন্ত কিছু হাইলাইট হবে না। ক্লিক করার দুই উপায়:
   - **Highlight বাটনে** ক্লিক → তোমার **লাস্ট-ইউজড রঙে** হাইলাইট হবে (বাটনের ব্যাকগ্রাউন্ড দেখেই বুঝবে কোন রঙে হবে)
   - অথবা **৮টি রঙের যেকোনো ডটে** ক্লিক → সেই রঙে হাইলাইট হবে **এবং সেটাই নতুন ডিফল্ট রঙ**
3. **ভুলে যান** — পেজ রিফ্রেশ করুন, ব্রাউজার বন্ধ করুন, কাল আবার খুলুন — হাইলাইটগুলো রঙ ও intensity সহ নিজে থেকেই ফিরে আসবে। ✅

### 🎨 কাস্টম কালার ও Intensity (গভীরতা)
1. লেখা সিলেক্ট করে টুলবারের **🎚️ বাটনে** ক্লিক করুন
2. **রঙ বাছুন** (যেকোনো রঙ!) এবং **Intensity স্লাইডার** দিয়ে হালকা↔গাঢ় সেট করুন (প্রিভিউ লাইভ দেখাবে)
3. **Apply to selection** চাপুন — এই রঙ + intensity সেট হয়ে যাবে, পরে Highlight বাটনে এক ক্লিকেই ব্যবহার হবে
4. পরে বদলাতে চাইলে: হাইলাইটে **ক্লিক** করে পপওভারের **Intensity স্লাইডার** সরান — সাথে সাথেই পরিবর্তন হয়ে সেভ হবে

### 🗑️ হাইলাইট মুছবেন যেভাবে (যেকোনো একটা)
| উপায় | কী করবেন |
|---|---|
| **১ ক্লিক + Delete** | হাইলাইট করা লেখায় **ক্লিক** করুন → পপওভারের **Delete** চাপুন |
| **টুলবারের 🗑️** | হাইলাইটসহ লেখা সিলেক্ট করুন → টুলবারের 🗑️ বাটন |
| **রাইট-ক্লিক** | লেখা সিলেক্ট করে রাইট-ক্লিক → **Remove highlights in selection** |
| **কীবোর্ড** | লেখা সিলেক্ট করে `Alt+Shift+D` চাপুন |

> 💡 ভুল করে মুছে ফেললে? পেজের নিচে সাথে সাথে **"Highlight removed — Undo"** টোস্ট আসবে — ৬ সেকেন্ডের মধ্যে **Undo** ক্লিক করলেই হাইলাইট ফিরে আসবে।

### আরও যা করতে পারবেন
- **রং বদলানো / Intensity / নোট / কপি:** হাইলাইট করা লেখায় **ক্লিক** করুন → পপওভারে রঙের ডটে ক্লিক করলেই সাথে সাথে রং বদলায় (সেভ অটো), intensity স্লাইডার, নোট লিখুন, টেক্সট কপি করুন।
- **একই লেখা দুইবার হাইলাইট হবে না:** আগের হাইলাইট আবার সিলেক্ট করে অন্য রঙে ক্লিক করলে ডুপ্লিকেট না হয়ে **রংটা বদলে যাবে**।
- **হাইলাইটার মোড (ঐচ্ছিক):** পপআপ বা `Alt+Shift+H` দিয়ে চালু করলে সিলেক্ট করামাত্রই অটো হাইলাইট হবে — ডিফল্টে বন্ধ থাকে যাতে ভুলে চালু না হয়।
- **তালিকা দেখা:** এক্সটেনশন আইকনে ক্লিক করুন → পেজের সব হাইলাইট, সার্চ বক্স, Intensity সেটিং, এক ক্লিকে জাম্প।
- **সব মুছে ফেলা:** পপআপের **Clear page** অথবা Settings → **Delete ALL data**।

## ⚙️ সেটিংস (Options)

আইকন → ⚙️ ক্লিক করুন। সেখানে পাবেন:

- **General** — মাস্টার সুইচ, টুলবার চালু/বন্ধ, হাইলাইটার মোড, iframe ও editable এলাকার অনুমতি, অ্যাক্টিভ রঙ
- **Sync across devices** — Chrome Sync-এ হাইলাইট সেভ (ডিফল্টে বন্ধ; চালু করলে ডেটা অটো কপি হবে)
- **Site exceptions** — যেসব ডোমেইনে এক্সটেনশন নিষ্ক্রিয় থাকবে
- **Your data** — Export ব্যাকআপ, Import (Merge/Replace), সব ডেটা ডিলিট, পরিসংখ্যান

## 🧠 এটা কীভাবে কাজ করে? (প্রযুক্তি)

প্রতিটি হাইলাইট সেভ করার সময় এক্সটেনশনটি মনে রাখে:

1. **লেখাটি নিজে** (selected text)
2. **আগে-পরের ~৪০ অক্ষরের কনটেক্সট** (prefix + suffix)
3. **কোন নম্বরের ম্যাচ** (occurrence index — একই লেখা পেজে কয়েকবার থাকলেও নির্ভুল)
4. **XPath ফলব্যাক** (রিস্কি ক্ষেত্রে শেষ চেষ্টা)

পেজ আবার লোড হলে পুরো ডকুমেন্টের একটি *normalized text index* বানিয়ে সেই প্যাটার্ন খোঁজা হয় এবং হাইলাইট ঠিক জায়গায় বসানো হয়। এজন্য DOM/লেআউট কিছুটা বদলে গেলেও হাইলাইট ঠিক থাকে। ডাইনামিক পেজে (lazy load, "load more") MutationObserver নতুন কনটেন্ট এলে আবার চেষ্টা করে।

**স্টোরেজ কাঠামো:** `chrome.storage.local` (বা ঐচ্ছিক `sync`) —
- `pm:settings` → সেটিংস
- `pm:page:{URL}` → ওই পেজের হাইলাইট রেকর্ডগুলো
- `pm:pages` → সব পেজের ইনডেক্স

| **পেজের লেখাই বদলে গেলে** | লেখা একেবারে বদলে গেলে/মুছে গেলে হাইলাইট পুনরুদ্ধার করা যায় না (স্বাভাবিক) |
| **একই URL-এর একাধিক iframe** | খুব বিরল ক্ষেত্রে একই URL-এর দুটি আলাদা iframe-এ হাইলাইট দুই জায়গাতেই দেখাতে পারে |
| **ওয়ান-টাইম পেজ** (OTP, পেমেন্ট) | লেখা প্রতিবার বদলায়, তাই অ্যাংকর মেলে না |

### Firefox-এ চালাতে চাইলে
Firefox MV3-ও সাপোর্ট করে, শুধু ৩টি ছোট পরিবর্তন লাগে:
1. `manifest.json`-এ `"background": { "service_worker": ... }` এর জায়গায় `"background": { "scripts": ["background/service-worker.js"] }` (আর `importScripts('/shared/common.js')` লাইনটি মুছে দিন, ফাইলের একেবারে উপরে `HL_PALETTE` কপি করে নিন অথবা `scripts` অ্যারেতে `"shared/common.js"` আগে যোগ করুন)
2. `chrome.*` কোড সরাসরি কাজ করে; না করলে উপরে `if (typeof browser !== 'undefined') { window.chrome = browser; }` যোগ করুন
3. (ঐচ্ছিক) `"browser_specific_settings": { "gecko": { "id": "persistmark@you" } }` যোগ করুন
