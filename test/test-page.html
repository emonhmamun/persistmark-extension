🖍️ PersistMark Test Page

Use this page to try the extension. Select any text below — the toolbar appears instantly; pick a color to highlight. Then refresh the page and watch your highlights reappear exactly where they were. 🎉

📝 Regular paragraphs

The quick brown fox jumps over the lazy dog. This classic pangram has been used to test typewriters and fonts since the late 19th century. Highlight any part of this sentence, refresh the page, and watch it reappear exactly where you left it.

Persistent highlighting relies on text anchoring: instead of remembering pixel positions, the extension remembers the surrounding context of every highlight, so it can relocate the text even if the page layout shifts slightly.

🌙 Dark background section

This section has a dark background — highlights stay readable here too

The extension detects the background behind every highlight and automatically adjusts the color for readability. Try selecting this paragraph.

⚡ Dynamic content (lazy loading)

Clicking the button adds a new paragraph after 2 seconds. If you highlighted something in it earlier, the extension re-applies it when the content returns.

✏️ Contenteditable (off by default)

This text is editable. Highlighting inside editable areas is disabled by default for safety — enable it in Settings → "Allow inside editable areas".

✅ Test checklist

  • Select any paragraph — the toolbar shows 8 colors on one side, the Highlight button on the other
  • Click Highlight — it highlights in your last-used color (the button shows that color)
  • Click any color dot — highlights in that color and makes it the new default
  • Click the sliders button — pick any custom color, set intensity, then Apply
  • Click a highlight — recolor, intensity slider, note, copy, delete
  • After deleting, an Undo toast appears — restore within 6 seconds
  • Refresh the page (F5) — highlights return with color and intensity intact
  • Highlight inside the dark section — colors adapt automatically
  • Select text and press Alt+Shift+D — removes highlights inside the selection
  • Click the extension icon — searchable highlight list; click an entry to jump to it

💡 Tip: to test local files, enable "Allow access to file URLs" for PersistMark in chrome://extensions.
